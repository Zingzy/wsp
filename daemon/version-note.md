Writes on a pull request as the person signed in to gh: git.prReply posts a reply under a comment on a line or a new comment in the conversation, its body as typed on stdin and at most 65,536 characters, a line reply carrying back the thread it names; git.prResolve resolves or unresolves a review thread; and git.prReact adds or takes off a reaction. A resolve and a reaction name their thread or item by a node id, refused before anything runs where it is not one's shape, and refused before the mutation where a read finds it on any pull request but the repository's one numbered. A pull request's page reads each comment's, review's and line comment's node id and reactions, with whether the signed-in person left each, and each line comment's review thread by id.
