A turn's HEAD move lines name the branch HEAD was on: git.snapshot stamps the branch it stands on, or a detached HEAD, beside the reflog length, and git.turn reads the turn's window back from that stamp, so a merge reads "Merged origin/main into fix/x", a reset "Reset fix/x to origin/main", a pull "Pulled into fix/x" and a rebase "Rebased fix/x onto main", one that was detached says "a detached HEAD", and a pull that rebases is one line.
