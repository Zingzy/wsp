git.prRead asks a pull request named by number with what its last read saw (its last update, head commit and state): one REST read compares them, and where none moved it answers unchanged with nothing else run and none of the GraphQL budget spent; a read with nothing seen makes no such read. A read the git host refused for its rate limit carries the code rate-limited, and a branch so refused never reads as having no pull request. git.prView reads the page on one GraphQL call in place of four, the newest 100 conversation comments with the rest marked cut.
