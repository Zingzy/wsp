fs.image reads a slate's image by its whole path, anywhere on the computer or inside the workspace it names with no link followed there, opened without blocking and judged on the handle, and answers its size, modified time, inode and change time with its bytes only where it is a regular file under the image cap whose own bytes name an image type the protocol allows, and says svg where an SVG document stands there; a folder, device, pipe or socket is refused not-a-file and a missing path not-found.
