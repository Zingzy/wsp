# Install on a Mac

{/* Written from apps/www/public/install (install_mac, put_on_path, restart_service), apps/www/src/downloads.ts, apps/desktop/src/host-lifecycle.ts, apps/web/src/shell/FirstRun.tsx. */}

wsp is one app for every Mac, with Apple silicon or an Intel chip. The app also gives you the `wsp` command line.

## Install with one line

1. Open Terminal.
2. Run the install line. Do not put `sudo` in front of it.

   ```sh
   curl -fsSL https://usewsp.com/install | sh
   ```

3. Open a new terminal window, and run `wsp --version`. It prints `wsp` and the version that you installed.

The line downloads the latest release from [GitHub](https://github.com/wsp-labs/wsp/releases), checks its sha256 and signature, puts `wsp.app` in `/Applications`, and opens it. It adds the `wsp` command to your `PATH`. If wsp is open, the line quits it first.

## Install from the download

1. Download [wsp-mac.dmg](https://github.com/wsp-labs/wsp/releases/latest/download/wsp-mac.dmg).
2. Open the file, and drag wsp to the Applications folder.
3. Open wsp from the Applications folder.

The download does not change your `PATH`. To run `wsp` by name, add `~/.wsp/bin` to your `PATH`, or run the install line once.

## What happens when wsp opens

When the app opens for the first time, it sets up the host. The host is the process that keeps your projects and threads and serves the app and the command line. It starts at every login, and again if it stops.

When you quit the app, it asks if your threads keep running or if wsp stops too. To change that answer, go to **Settings**, then **General**, then **When you quit**. The host's log is `~/.wsp/host.log`.

<Image src="/shots/docs-first-launch.webp" alt="The first wsp window on a new Mac, with one Get started button." />

The first window has one **Get started** button. Select it, and then go to the next page, [Your first thread](/start/first-thread).

The first window also says that wsp sends anonymous usage counts to PostHog. To turn the counts off, select **Privacy settings**.

## Install a given version or update

- To install one release instead of the latest, set `WSP_VERSION` for the `sh` that runs the line. For example: `curl -fsSL https://usewsp.com/install | WSP_VERSION=1.2.3 sh`.
- To move to the latest release, run the install line again. It replaces the app where it is and restarts the host on the new version.
