# Slate catalog

{/* Written by apps/docs-next/scripts/slate.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

What `slate_catalog` answers, and `wsp slate catalog` prints: the index with no name, and one entry for each piece, source and chapter named below. A slate is written in this kit with `slate_write`.

## The index

```text
Slate kit wsp/2, JSX-like text. Pieces (attributes, ! required, (a|b) the only values; <items>):
column: gap(tight|normal|loose) align; children
grid: columns! gap(tight|normal|loose) align; children
row: gap(tight|normal|loose) align wrap; children
section: title! note collapsible open align onChange; children
text: value! tone emphasis mono size(small|normal|large) lines placeholder
heading: value! level(title|section|label)
markdown: value!
number: label! value! format unit tone note size(normal|large) trend
meter: label! value! max note tone format(percent|value|fraction|tokens|bytes|none)
bars: label! items! key name! value! tone max format(percent|value|none)
chart: label! items! x value format unit tone height(small|normal|large) stack; <series label! value! tone>
diagram: value! label
timeline: label! items! name! start end state(done|running|failed|waiting) group now
treemap: label! items! name! value! group format
donut: label! items! name! value! format unit
image: src! caption
images: items! src! caption layout(strip|gallery|compare)
sparkline: label! values! tone
table: items! key empty rows; <col title! value! tone emphasis mono align width(fit|fill)> <action label! onPress>
checklist: items! key title! done! state(pending|working|done) note editable empty onChange
facts: layout(line|grid); <fact label! value! tone emphasis mono>
status: value! tone
chip: value!
ring: label! value! max format(percent|value|fraction) tone note
output: run! label lines wrap
button: label! variant(default|primary|quiet|danger) held note size(normal|small) onPress
input: label! value! lines kind(text|number|password) placeholder held mono submit onChange onSubmit
select: label! value! placeholder held onChange; <option value! label>
choices: label! value! answer held onChange; <option value! label note>
toggle: label! value! note held onChange
empty: title! body
Every piece: id, when={cond}; items take when too. tone: default muted good warning bad info accent. emphasis: normal strong quiet. format, where a line lists none: plain tokens bytes percent usd inr duration integer.
section, column, grid: pad none tight normal loose; surface="inset" sets the card ground; align start center end, else children fill the width.
bars compare categories; time is a chart, x in ms or ISO; shares a donut, sizes a treemap, spans on a clock a timeline; a flow is a diagram; a screenshot or plot is an image from its path on the thread's computer, or an https address the person allows.
Sources, read only:
thread: id title agent model status turns lastTurn cost tokens context changes plan waitingOn subagents[] ...
usage: account windows[] session week status note ...
cost: rateUsdPerHour accruedUsd
time: now today zone
git: branch head ahead behind changed ...
pr: number url state draft branch headSubject mergeable review checks[] word ...
Declarations: <value name start> <secret name> <derived name value> <run name cmd env args stdin on timeout every always once confirm then tool resource> <file name> <when change={$path} or done={$run} do={steps}>
Steps: set toggle start cancel send steer queue fill open copy pane. Functions: percent pct tokens bytes usd number duration ago until date time weekday plural word upper lower trim short round floor ceil abs min max clamp str num bool concat json lines split replace contains startsWith endsWith orElse exists isNull coalesce if len count sum avg first last at append pluck join. ago(t) "30s ago", until(t) "in 4m".
After |: where sortBy groupBy take skip count sum min max avg first last pick map distinct flatten join format. $run reads state exit out err json; a secret only .set .len.
Rules:
1. One <slate>, one root piece, declarations beside it. Give an id to a piece you will change.
2. prop="text" is literal; prop={formula} reads live data or $values with operators, a ? b : c, [lists], {records} and functions, never methods or =>. A text child with {holes} fills a sentence.
3. Props are meaning, never style. held is a sentence that disables: bind it to a condition; "" or false enables.
4. A list binds to items; item and index read the row.
5. A press reaches you only through send("literal text", $path); <when> chains run without you.
6. Small edit: patch by id, <props id="price" value={$spot.json.v} />; bigger: resend the whole slate with if_version.
7. Simple and airy unless asked for more: few pieces, one idea per section, short labels, no emoji. Separate things by layout, never by ·, • or |.
8. One heading per section: its title or a heading, in sentence case, never bold text.
9. Status and last-checked lines small and muted, beside their subject.
10. Actions at the end of their row; one primary per section.
11. mono only for figures, ids, times and paths.
12. Every live number says its window and unit. Show a run's json fields, never its raw out; times through date(), time() or ago().
13. Nothing centered but a lone figure or card.
14. Use the slate tools, never wsp from a shell.
15. A secret the person types goes in a <secret> input, never a file or the chat. One in a file stays there for the run to read, never you.
16. A button asked for where the project has no UI goes here: the slate is its UI, and the reply says so.
<slate title="Issue">
  <value name="id" start="" />
  <run name="check" cmd='gh api "repos/{owner}/{repo}/issues/$ID"' env={{ ID: $id }} />
  <when change={$id} do={start($check)} />
  <column>
    <input label="Issue" value={$id} />
    <text when={$check.exit == 0}>{$check.json.title}</text>
    <button label="Fix it" onPress={send("Fix this issue.", $id)} />
  </column>
</slate>
More: slate_catalog <piece, source, runs, patch, functions, steps, handlers or examples>.
```

## Pieces

### column

```text
column (core): Stacks children top to bottom.
  gap: tight|normal|loose
  align: start|center|end|stretch
  pad: none|tight|normal|loose
  surface: plain|inset
events: none; holds children
sketch: [column-2 column gap=tight]
example: <column gap="tight"><text>One</text><text>Two</text></column>
```

### grid

```text
grid (core): Children in 2 to 4 equal columns, one column under 360 px.
  columns: integer, required, 2 to 4
  gap: tight|normal|loose
  align: start|center|end
  pad: none|tight|normal|loose
  surface: plain|inset
events: none; holds children
sketch: grid of 3  [grid-1 grid]
example: <grid columns={3}><number label="Open" value={3} /><number label="Done" value={9} /><number label="Failed" value={0} /></grid>
```

### row

```text
row (core): Places children side by side.
  gap: tight|normal|loose
  align: start|center|end|between
  wrap: boolean
events: none; holds children
sketch: [row-1 row align=between]
example: <row align="between"><text>Left</text><text>Right</text></row>
```

### section

```text
section (core): A titled group, optionally collapsible.
  title: string, required, formula
  note: string, formula
  collapsible: boolean

  align: start|center|end
  pad: none|tight|normal|loose
  surface: plain|inset
events: onChange; holds children
sketch: Files changed  [section-1 section collapsible]
example: <section title="Files changed" collapsible><text>None yet</text></section>
```

### chart

```text
chart (core): Lines over a list, oldest first; stack piles the <series>.
  label: string, required, formula
```

### diagram

```text
diagram (core): A Mermaid diagram: a flow, a sequence or a state machine; value={`...${$step}`} shows the live step.
  value: string, required, formula; Mermaid source; a text child is taken as written, braces and all. Labels a few words, decisions short questions; detail goes in a text beside it. Under about 15 nodes; past that, split it or summarize
  label: string, formula
events: none; a text child fills value
sketch: Deploy  flowchart LR (+3 lines)  [diagram-1 diagram]
```

## Sources

### thread

```text
thread (core): This thread: status, last turn, context, cost, tokens, changes, plan.
  thread.turns: number
  thread.id thread.title thread.agent thread.model thread.effort thread.access thread.computer thread.project thread.folder thread.waitingOn: string
  thread.status: starting|working|needs-you|failed|done|resting
  thread.lastTurn: { status, durationMs, waitedMs, startedAt, endedAt, model }
  thread.cost: { usd }
  thread.tokens: { input, output, cached, cacheWrite, reasoning }
  thread.context: { used, window, free, percent }
  thread.changes: { files: { path, kind, additions, deletions }[], from, to, moved: any[], shared }
  thread.plan: { steps: { text, state: pending|working|done }[], text }
  thread.subagents: { id, title, state, startedAt, endedAt }[]
  thread.messages: { recent: { who, at, text }[], last }
update: push; scope: the slate's own thread; cost: none beyond today
note thread.context: the latest turn that reports it; null on an agent that does not
note thread.changes.files: the latest session.changes
example: {percent(thread.context.used / thread.context.window)}
```

```text
tree (working): The thread's root and every thread under it.
  tree.root: { id, title, status, agent, computer }
  tree.parent: { id, title, status, agent, computer }
  tree.children: { id, title, status, agent, computer, costUsd, startedAt, endedAt }[]
  tree.all: { id, title, status, agent, computer, depth }[]
  tree.counts: { working, needsYou, done, failed, resting }

```

```text
usage (core): The plan windows of the account the thread runs on.
```

### pr

```text
pr (core): The pull request of the thread's branch and its checks.
  pr.readAt: time
  pr.draft: boolean
```

### runs

```text
runs: a command the slate starts with no turn of yours.
<run name="check" cmd='gh api "repos/$REPO/issues/$ID"' env={{ REPO: $repo, ID: $id }} every={60} />
<run name="py">{`python3 -c "print('both quotes')"`}</run>
Each attribute:
name: the run is read as $name.
cmd: the literal command, run by bash -c in the thread's folder. Single quotes outside double ones; the block form above takes any text.
env={{ ID: $id }}: values it reads as $ID. args={[$a]}: as $1. stdin={$x}: on standard input. A secret goes only in env or stdin; one in a file, the command reads itself, never through you.
every={60}: starts it again every 60 seconds, at least 10, while the Slate tab is on screen; at once when it comes back.
always: with every, ticks while the tab is not on screen too.
once: a start while it still runs is skipped; without once it stops and starts again.
stream: fills lines as it prints, the last 500, so an output piece shows them live.
timeout={60}: seconds before it is stopped, at most 600.
on="host": runs on the host's computer, not the thread's.
confirm="Stop it?": asks the person every start; a formula works too.
then='python3 x.py': pipes its raw result to that command; its stdout as JSON becomes json, out stays raw.
tool="server.tool" args={{ id: $id }}, or resource="server:uri": calls an MCP tool instead; slate_catalog <server> lists its tools.
start($run) in a handler or <when> starts one. The person allows each command once, on the slate, when it first wants to start: at the write for an every= run, at the first press or <when> for the rest. Until then it reads held; allowing it starts it at once. slate_state start runs only what they allowed "Always in this thread".
$run reads state why exit out err json lines startedAt endedAt ms runs cut stale refreshing text; state is idle (never started) held running done failed cancelled.
json is out parsed as JSON. Before a first result or after a failure, out and json are empty and len of them 0: show a figure with when={$run.exit == 0}. stale: the command changed since this result. Output is scrubbed of secrets.
<value> state and each run's last result outlive an app or host restart.
Chain: <when done={$check} do={set($ok, $check.exit == 0)} />; done fires on any outcome.
Code only the slate uses goes in <file name="x.py"> and runs as $SLATE_DIR/x.py; project code runs where it is.
A tool's json is its structured result, else its text parsed; out is its text; one marked text only keeps json empty unless its text is JSON. The person allows a server once per thread, a destructive tool every start. A secret in args returns as [secret:name].
```

### steps

```text
List steps, after | (item and index read the element):
```

### handlers

```text
Handler steps, in onPress, onSubmit, onChange and <when do>; one step or [a, b], at most 6:
set($path, value): writes a value; later steps read the new value. Consent: none. set($step, 2)
toggle($path): flips a boolean value. Consent: none. toggle($showDone)
start($run): starts a run; does not wait; its end fires <when done>. Consent: the person approves the command once. start($check)
cancel($run): stops a running run. Consent: none. cancel($tests)
send("text", $path, ...): a message to the agent: the text, then slate: {...} with the paths as data. Consent: a press is the consent; from a reaction, one approval per slate. send("Fix the failing check.", item.name)
steer("text", $path, ...): as send, into the running turn. Consent: as send. steer("Look at the failing check first.")
queue("text", $path, ...): as send, after the running turn (a send until the flag lands). Consent: as send. queue("Then open the pull request.")
fill("text", $path, ...): puts the text in the composer, not sent. Window only, on a press. Consent: none; a press only. fill("About this branch:", git.branch)
open(url): opens an http, https or mailto link. Window only, on a press. Consent: once per domain; a press only. open(pr.url)
copy(text): copies to the clipboard. Window only, on a press. Consent: none; a press only. copy(git.head)
pane("kind"): opens a right panel tab. Window only, on a press. Consent: none; a press only. pane("pr")
```

### patch

```text
patch: elements without <slate>, sent as text to slate_write; one write may hold several.
<props id="price" tone="warning" />: merges these props into the piece.
<text id="eta">Ready</text>: a piece with an id that exists replaces it whole, children too.
<add under="list" at={0}><text id="new">New</text></add>: adds pieces under a piece, at an index from 0, else last.
<move id="new" under="other" at={1} />: moves a piece.
<remove id="new" />: removes a piece and what it holds. <remove name="hist" /> removes a declaration.
<value name="hist" start={[]} />, <run ...>, <derived ...>, <file name="x.py">...</file>: adds the declaration or replaces the one of that name.
<clear /> empties the slate; <undo /> goes back one write. Each stands alone in its write.
For anything bigger, resend the whole <slate> with if_version set to the version you read.
version, which every write and read answers, counts the slate's edits and is what if_version takes; wsp/2 and schema 2 name the format.
check with press walks a press and its <when> chain on a copy: nothing runs and nothing is sent, and it says what would start.
check with values {"$run.json": {...}, "$run.exit": 0} previews the panel for a result the run has not had yet.
```
