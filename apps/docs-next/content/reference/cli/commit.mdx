# wsp commit

{/* Written by apps/docs-next/scripts/cli.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

```text
usage: wsp commit <thread> [--message "<message>"] [--file <path>]...
  commits every changed file in the folder the thread works in, other threads'
  changes there included, or the files named; without a message the thread's
  agent drafts one

  --message    the commit message, a subject line, a blank line, then the body,
               -m for short; the thread's agent drafts it without one
  --file       a file to commit, by path from the checkout's top, once per file;
               every changed file without one
  --json       print the raw protocol values, one JSON object per line, with
               everything else on stderr
  --state      the state file the host serves
  --host       run the line against a host on your account, by the name wsp
               hosts lists it under; WSP_HOST names one for a whole shell
```
