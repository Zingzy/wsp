# wsp worktree

{/* Written by apps/docs-next/scripts/cli.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

```text
usage: wsp worktree <project> <branch>
  a worktree of the project's repo on the branch, for an agent to work in by
  path or to start a thread in: the one git already has the branch checked out
  in, wherever it is, else one wsp makes under its own folder, from the project
  folder's current commit for a new branch, with the folder's .env files and
  installed dependencies carried in; prints its path

  --json     print the raw protocol values, one JSON object per line, with
             everything else on stderr
  --state    the state file the host serves
  --host     run the line against a host on your account, by the name wsp hosts
             lists it under; WSP_HOST names one for a whole shell
```
