# wsp logout

{/* Written by apps/docs-next/scripts/cli.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

```text
usage: wsp logout [<id>]
  sign this computer out of your account, which drops the hosts it reached
  through it; with an id it signs another of your computers out, and every host
  drops what it admitted for that one

  --state    the state file: this word first, else WSP_HOME's state.json, else
             ./.wsp/state.json when the current directory is a checkout of wsp,
             else state.json in the home the running host serves
```

No MCP tool: takes away a token of this person's and the access it bought, which belongs with the person whose account it is.
