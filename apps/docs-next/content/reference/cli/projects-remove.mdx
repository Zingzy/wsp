# wsp projects remove

{/* Written by apps/docs-next/scripts/cli.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

```text
usage: wsp projects remove <project> [--yes] [--force]
  takes a project out of this wsp; its folder is left where it is, on this
  computer or on a computer you joined, a project with a machine standing on it
  is refused naming them, and one whose checkout on a computer of yours holds
  work no remote has is stopped naming it

  --yes      go ahead without being asked
  --force    remove it even where its checkout on a computer of yours holds work
             no remote has, which goes with it
  --json     print the raw protocol values, one JSON object per line, with
             everything else on stderr
  --state    the state file the host serves
  --host     run the line against a host on your account, by the name wsp hosts
             lists it under; WSP_HOST names one for a whole shell
```

MCP tool: [`projects_remove`](/reference/mcp-tools#projectsremove).
