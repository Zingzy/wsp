# wsp mcp install

{/* Written by apps/docs-next/scripts/cli.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

```text
usage: wsp mcp install --agent <id> [--agent <id>] [--host <alias>] [--json]
       [--remove]   (claude, codex, gemini, opencode)
  put the wsp tools, this skill and wsp's own section of this project's
  AGENTS.md into that agent (claude, codex, gemini, opencode); --agent repeats,
  --remove takes it back out, and --json prints what each agent took

  --agent     the agent to write the server, this skill and wsp's own section of
              AGENTS.md into, by catalog id (claude, codex, gemini, opencode);
              repeats, and off a terminal every agent whose own command is on
              this computer's PATH takes it
  --remove    take the server, the skill and that section back out of those
              agents instead
  --json      print what each agent took as one JSON object
  --state     the state file the host serves
  --host      write the server against a host on your account, by the name wsp
              hosts lists it under, so the tools drive that host
```

No MCP tool: writes an agent's own config and skills folder, which is done once from a shell.
