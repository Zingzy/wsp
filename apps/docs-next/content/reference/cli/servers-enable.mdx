# wsp servers enable

{/* Written by apps/docs-next/scripts/cli.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

```text
usage: wsp servers enable <name> [<thread>] [--on <computer>] --agent <id>
       [--scope <user|home|local|project>] [--project [<name>]]
  turns an MCP server that was turned off on again

  --agent      the agent whose config names the server, by its catalog id as wsp
               servers shows it
  --on         the computer to read, by the name wsp computers shows; this
               computer without it, and a thread names its own
  --scope      user, home, local or project, as wsp servers shows it; user
               without it
  --project    the project scope: alone with a thread, the thread's own project,
               or the project's name with --on
  --json       print the raw protocol values, one JSON object per line, with
               everything else on stderr
  --state      the state file the host serves
  --host       run the line against a host on your account, by the name wsp
               hosts lists it under; WSP_HOST names one for a whole shell
```

MCP tool: [`servers_enable`](/reference/mcp-tools#serversenable).
