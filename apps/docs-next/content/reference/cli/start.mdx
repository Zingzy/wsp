# wsp start

{/* Written by apps/docs-next/scripts/cli.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

```text
usage: wsp start <link> [--project <name>] [--agent <id>]
       [--model, --effort, --access <word>]
  a thread off a GitHub issue or pull request link, the issue or the pull
  request its first message; an issue's thread runs in the project folder, a
  pull request's in a worktree on its branch

  --project    the project by name or id where two computers hold the link's
               repository; this computer's without it
  --agent      which agent runs the thread, by its catalog id (claude, codex,
               opencode, cursor); the project's own default without it
  --model      the model the turn runs on, by the agent's own slug
               (claude-sonnet-5); the thread's own without it
  --effort     how hard the agent thinks, by its own word (low, medium, high,
               xhigh, max); absent on a new thread means the agent's default; on
               send, the thread's own
  --access     how far the agent may go without asking: ask, auto-edit, full or
               plan, refused where the agent has no such mode; without it, the
               project's, else the agent's default, else full
  --json       print the raw protocol values, one JSON object per line, with
               everything else on stderr
  --state      the state file the host serves
  --host       run the line against a host on your account, by the name wsp
               hosts lists it under; WSP_HOST names one for a whole shell
```

MCP tool: [`start`](/reference/mcp-tools#start).
