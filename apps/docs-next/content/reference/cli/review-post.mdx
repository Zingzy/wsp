# wsp review post

{/* Written by apps/docs-next/scripts/cli.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

```text
usage: wsp review post <thread> [--verdict comment|approve|request-changes]
       [--summary "<text>"]
  posts a reviewer thread's review on its pull request as you, its ticked
  comments on their lines

  --verdict    comment, approve or request-changes; the draft's own, the
               reviewer's word unless you changed it, without it
  --summary    the review's summary, written over the draft's
  --json       print the raw protocol values, one JSON object per line, with
               everything else on stderr
  --state      the state file the host serves
  --host       run the line against a host on your account, by the name wsp
               hosts lists it under; WSP_HOST names one for a whole shell
```

MCP tool: [`review_post`](/reference/mcp-tools#reviewpost).
