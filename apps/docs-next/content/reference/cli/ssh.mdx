# wsp ssh

{/* Written by apps/docs-next/scripts/cli.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

```text
usage: wsp ssh <workspace>
  carries one ssh connection to the workspace's own ssh server, starting it
  there, over this computer's stdin and stdout: the ProxyCommand wsp's ssh
  config gives every wsp- alias, so `ssh wsp-<name>` and an editor's remote
  window land inside the workspace

  --json     print the raw protocol values, one JSON object per line, with
             everything else on stderr
  --state    the state file the host serves
  --host     run the line against a host on your account, by the name wsp hosts
             lists it under; WSP_HOST names one for a whole shell
```

No MCP tool: a proxy for an ssh client on the computer the host runs on, piping raw bytes; an agent has no ssh client there to hand it to.
