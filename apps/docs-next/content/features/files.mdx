# Files

{/* Written from apps/web/src/files/ (FilesSurface.tsx, FilePreviewSurface.tsx, FileFinder.tsx), apps/web/src/components/files/, daemon/crates/wsp-daemon/src/fs.rs. */}

The Files pane shows the files in the thread's folder, on the computer the thread runs on. You can browse the tree, read a file, find a file by name and search the files for a word. The pane only reads. To change a file, use your editor or the [Changes pane](/features/changes).

To open it, click **Add a panel**, the **+** at the top of the right panel, and pick **Files**. If the right panel is empty, pick it from the list there. In that menu or that list, `F` picks it too. The pane opens only while the thread's computer is on.

## Browse the tree

The tree starts at the folder the thread works in, and follows the agent when it moves to another folder. To keep the tree on one folder, click the pin, **Stay in this folder**.

- Type in **Search files** at the top of the tree to filter it by name.
- Click **Refresh files** to read the folder again.
- Click **New thread in this folder** to start a thread there.

Right-click a file for **Open file**, **Show in Changes** and **Copy path**.

## Read a file

Click a file to open it in its own tab. Code shows with syntax colors. Markdown shows rendered. Click **Show markdown source** to see the text, and **Show rendered markdown** to go back. Click **Reload file** to read it again.

A very large file shows only its start, and says so. A binary file, an image too, shows its size and no preview.

To open the file in your own editor, click **Open in editor**. See [Open in your editor](/features/editor).

A file path in the terminal opens here too. `Cmd`-click it on a Mac, or `Ctrl`-click it elsewhere, and the file opens at its line.

## Find a file

Press `mod+p` and type part of the name. The letters you type must come in order in the path, but need not be next to each other. Pick a file to open it.

## Search in files

Press `mod+shift+f` and type a word. The search finds every line that holds the word, in any case. Pick a line to open the file at that line.

If a search finds too much, it stops and asks you to type more.

## What both searches skip

Both searches skip the files that `.gitignore` and `.ignore` name, and hidden files and folders. Search in files also skips large files and binary files.

`mod` is `Cmd` on a Mac and `Ctrl` elsewhere. On a computer that is not a Mac, `Ctrl+p` goes to the terminal while the terminal has focus, so click outside the terminal first.
