# Open in your editor

You can open a thread's folder, or one of its files, in the editor you already use. For a thread on a computer you added, wsp opens the editor over ssh, so the editor works on that computer's files.

<Image src="/shots/editor.webp" alt="The Open menu on a thread on gpu-box, with the installed editors." />

## Open a folder or a file

- To open the thread's folder, click **Open** in the thread's top bar, or press `mod+o`.
- To pick another editor, click the arrow beside **Open**, then **Choose an editor**. The one you pick becomes your default.
- To open a file, click **Open in editor** on the file's tab in the [Files pane](/features/files). The editor opens the file at its line.

`mod` is `Cmd` on a Mac and `Ctrl` elsewhere. You can also set the default in **Settings > General > Open files in**.

## Open a thread on another computer

For a thread on a computer you added, the menu lists only the editors that work over ssh. The editor connects to an ssh host such as `wsp-acme-lab`, over wsp's own link, so you set up no ssh login of your own.

The first time, the dialog **Open in your editor over SSH** asks to add one line to `~/.ssh/config`. The line covers only hosts named `wsp-*`. While your editor is connected, the thread's computer can reach the ports the editor forwards, the files it asks to open, and your editor's git sign-in.

Click **Add to SSH config** to go on. To take the line out, turn off **Editors over ssh** in Settings > General.

VS Code, Cursor and VS Code Insiders need their Remote SSH extension. If it is missing, wsp prints the command that installs it:

{/* generated: editor-extensions */}

| Editor | Command that installs the extension |
|---|---|
| VS Code | `code --install-extension ms-vscode-remote.remote-ssh` |
| Cursor | `cursor --install-extension anysphere.remote-ssh` |
| VS Code Insiders | `code-insiders --install-extension ms-vscode-remote.remote-ssh` |

{/* end generated: editor-extensions */}

Cursor also works with `ms-vscode-remote.remote-ssh` if it is already installed.

## When an editor does not open

If wsp says no editor is installed, or that a file cannot open in your editor, see [Troubleshooting](/reference/troubleshooting).
