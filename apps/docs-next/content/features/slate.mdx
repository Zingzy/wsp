# Slate

{/* Written from apps/web/src/slate/ (SlateSurface.tsx, consent.tsx, standing.tsx, store.ts), packages/protocol/src/slate/catalog.ts and packages/runtime/src/slates.ts. */}

A slate is a panel beside a thread that the agent builds and keeps current. It holds checklists, live numbers, charts, forms and buttons. You press a button or fill in a field, and the agent reads what you did. Status updates that would fill the chat go there instead.

<Image src="/shots/slate-cart.webp" alt="A slate for a cart rounding fix: progress, an editable checklist, the files changed and a button to go on." />

Ask for one to watch a pull request's checks, walk through a deploy, follow a plan as a checklist you can edit, watch live traffic, or see a diagram of the code.

## Open the slate

Click **+** at the top of the right panel and pick **Slate**, or press `S` in that menu. If the right panel is empty, pick the pane in the list it shows.

The tab opens by itself the first time the agent writes a slate. When a turn changes it, click **Updated the slate** under the reply to open the tab. Each thread has one slate. A sub-thread has none, and its lead shows its work instead.

## Allow a command

A slate gets its live values from commands that run in the thread's folder and reach what the agent reaches. A refresh runs a command, not a turn, so it costs no tokens. The first time a command wants to run, the slate shows **Run this command?**. Read it, then pick one:

- **Don't** keeps it from running.
- **Run once** runs it this time and asks again next time.
- **Always in this thread** runs it from now on. The agent can then start it too.

To take back a yes, open the slate's menu, click **Approvals**, and click **Revoke** beside the command.

## Secrets

A field for a token, a key or a password is a secret field. What you type there goes to the command that needs it, never to the agent or the chat, and output that holds it shows the secret hidden. To make the slate ask again, open its menu and click **Forget secrets**.

## How the agent hears you

A button that sends puts one message into the thread, with the button's label and the values it names. Other presses and fields change the slate only. The agent reads them when it next reads the slate.

The slate's menu also has **Undo**, **Clear**, **Stop runs** and **Copy as text**.

## What stays and what goes

The slate's values stay after you restart the app. When you [rewind](/features/rewind) a thread, its slate goes back to how it stood at that reply, and your approvals and secrets stay. Deleting a thread deletes its slate.

## Build a slate from your agent

Any agent with the wsp tools can build a slate with `slate_catalog`, `slate_write`, `slate_state` and `slate_read`. The [Slate catalog](/reference/slate) lists every piece a slate can hold.
