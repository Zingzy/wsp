# Computers behind a firewall

[Add a computer](/features/add-a-computer) needs your Mac to reach the new computer over ssh. A computer behind a firewall or a home router often takes no connection in. It can join with a one-time code instead and dial out to your host, so nothing on it has to be open. It dials again at every boot.

<Image src="/shots/docs-firewall-computer.webp" alt="The Name and SSH login rows of a computer that joined with a code: It joined with a code and has no login." caption="A computer that joined with a code has no ssh login." />

## Join a computer

The computer that joins must run Linux, and you need root on it.

1. On the computer the app runs on, run `wsp add` with no argument. It prints one `wsp join` line for each address your host answers on:

   ```txt
   wsp add: a computer you own joins by dialing this host. On that computer, with wsp installed:
     wsp join http://192.168.1.20:4420 --code <code>
   ```

2. Install wsp on the computer that joins. See [Install on Linux](/install/linux).
3. On that computer, as root, run the `wsp join` line that reaches your host.

The code works once, for 10 minutes. If it runs out, run `wsp add` again for a new one. A code reaches only the host that printed it.

The computer then shows in **Settings > Computers** and in `wsp computers`. Its page says it joined with a code and has no login.

| Flag | What it does |
|---|---|
| `--code <code>` | The code that `wsp add` printed. |
| `--code-file <path>` | Reads the code from this file, and deletes the file before it dials. Use it to keep the code out of your shell history. |
| `--name <name>` | The name the computer goes by in wsp. |

If the join fails, see [Troubleshooting](/reference/troubleshooting).

## When the two computers share no network

The `wsp join` lines use your host's own addresses, so the joining computer must reach one of them. If it cannot, link your host to the relay:

```sh
wsp host link
```

The relay gives your host an https address that answers from anywhere. `wsp add` then prints one more join line, for that address.

The relay knows which computers you own, where each answers, and which key each proves. No join code, device token, private key or byte of a thread passes through it. The link between a joined computer and your host is sealed with a key the two ends agree on, so the relay cannot read it. The app is different. When the app reaches your host over the relay, the connection runs through Cloudflare's tunnel, and Cloudflare can read it. You can skip the relay, or run your own. See [What leaves your computer](/how/network) and [Run your own relay](/guides/own-relay).

## Take a computer out

Run one command on each computer:

1. On the host, run `wsp remove <computer>`, or click **Remove** on the computer's page. The host forgets the computer, but cannot take the wsp service off it.
2. On the computer itself, as root, run `wsp leave`. It takes the service and wsp's files off. Your work folder stays.

If the computer was offline when you removed it, run `wsp leave` on it once it is back. If the host is gone, run `wsp leave` on the computer alone.

For a step-by-step setup of a computer at home, see [A box behind a firewall](/guides/behind-a-firewall).
