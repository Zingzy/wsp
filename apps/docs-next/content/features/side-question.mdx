# Side question

{/* Written from apps/web/src/components/chat/AsideSurface.tsx, asideStore.ts and composerWords.ts, the side question lines in packages/protocol/src/words/thread.ts, packages/adapter-claude/src/aside.ts and packages/adapter-codex/src/adapter.ts. */}

A side question is a question about a thread that the thread never keeps. The agent answers it from the thread's conversation, in a pane beside the thread, and does not remember it on its next turn. Use one when you want to know something about the work without changing it, such as "which file did you change for the login bug?"

## Ask a side question

1. In the composer, type `/btw` and then your question. For example: `/btw what does the retry loop in fetch.ts do?`
2. Send it.

The Side question pane opens with your question and says **Asking**, then **Answering** as the words arrive. You can ask while the thread works. A side question never starts a turn and never stops one.

## Who answers

The thread's own agent answers, on a copy of the conversation that goes away after the answer.

- Claude Code answers with the thread's model and runs no tools, so it answers only from what the conversation holds. If the answer needs a tool, send it as a normal message instead.
- Codex answers with the thread's model and can run commands that only read. Its whole answer arrives at once.

OpenCode and Cursor do not take side questions. In a thread on one of those, the composer asks you to drop the `/btw`.

## Ask again, or close

A new `/btw` replaces the question in the pane. The agent does not see your earlier side questions.

To close the pane, press `Esc`, close its tab, or go to another thread. The pane is not kept after a reload. Only `/btw` opens it.
