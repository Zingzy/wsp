The terminal opens a shell on the computer a thread runs on, in the thread's folder. It is Ghostty's own terminal, drawn with your Ghostty config: your font, your colors and your cursor.

## Open a terminal

- In the drawer under the thread, press `mod+j` to open or close it. With no thread open, the drawer opens a shell in your home folder on the computer you sit at.
- In the right panel, click **+** at the top and pick **Terminal**, or press `T` in that menu. If the right panel is empty, pick the pane in the list it shows.

The shell is your login shell on that computer. A command that opens a web page, such as a sign-in, opens it on the computer you sit at.

## Tabs and splits

`mod` is `Cmd` on a Mac and `Ctrl` elsewhere. While a terminal has focus:

| Chord | What it does |
|---|---|
| `mod+d` | Split the terminal. On a Mac only. |
| `mod+n` | Open a new terminal. On a Mac only. |
| `mod+=` | Zoom in. |
| `mod+-` | Zoom out. |
| `mod+0` | Reset the zoom. |

Off a Mac, `Ctrl+D` and `Ctrl+N` go to the shell, so use the right-click menu to split or open a terminal. That menu also has **Copy**, **Paste**, **Clear**, **Close terminal** and **Add to chat**, which puts the selected text into the composer. You can change these chords in Settings > Keybindings. See [Keyboard shortcuts](/features/shortcuts).

## Keys the terminal keeps

On a Mac, the app's `Cmd` chords work everywhere, the terminal included. Elsewhere `mod` is `Ctrl`, and a shell needs many `Ctrl` keys, so a focused terminal keeps most `Ctrl` chords for itself. `Ctrl+b` still reaches `tmux`, for example. In a terminal, open the sidebar with `Ctrl+Shift+b` and the palette with `Ctrl+Shift+p`.

## Copy, paste and links

| | On a Mac | Elsewhere |
|---|---|---|
| Copy the selection | `Cmd+C` | `Ctrl+C` or `Ctrl+Shift+C` |
| Paste | `Cmd+V` | `Ctrl+Shift+V` or `Shift+Insert` |
| Open a link or a path | `Cmd`-click | `Ctrl`-click |

`Ctrl+C` copies only while text is selected. Without a selection, it interrupts the shell. A web address opens in your browser, and a file path opens in the [Files pane](/features/files) at its line.

## Reloads

The shell runs on the thread's computer, not in the window. If you reload the app, the shells come back as tabs with their recent output.

## Your Ghostty config

wsp reads the Ghostty config on the computer that runs wsp and draws every terminal with it. It reads these files, and a later file wins:

- `~/.config/ghostty/config.ghostty`, then `~/.config/ghostty/config`, or the `ghostty` folder under `XDG_CONFIG_HOME` if that is set.
- On a Mac, also `~/Library/Application Support/com.mitchellh.ghostty/config.ghostty`, then `config` in the same folder.

wsp follows `config-file` lines and reads `theme`, picking the light or dark side to match the app. Your own lines win over the theme's. It reads these keys and leaves the rest:

| Key | Notes |
|---|---|
| `font-family` | Repeat it for fallback fonts. |
| `background`, `foreground`, `selection-background`, `cursor-color` | Six-digit hex colors. |
| `palette` | Colors 0 to 15. |
| `cursor-style`, `cursor-style-blink` | `block`, `bar`, `underline` or `block_hollow`. |
| `window-padding-x`, `window-padding-y` | |
| `background-opacity` | From 0 to 1. |

To see what wsp read, run `wsp terminal config`. It prints the files it read and each key it took. Pass `--scheme light` or `--scheme dark` to pick the side of a theme.

## Pick another font

To use another font than your Ghostty font, click **Terminal font** in the drawer and type the name of a font installed on this computer. Leave it empty to go back to your Ghostty font.
