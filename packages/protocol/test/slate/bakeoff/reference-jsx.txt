actions: set, toggle, send, steer, queue, fill
functions: percent, pct, tokens, bytes, usd, number, duration, ago, until, date, time, weekday, plural, upper, lower, trim, short, round, floor, ceil, abs, min, max, clamp, str, num, bool, len, count, sum, avg, first, last, pluck, join, contains, startsWith, concat, orElse, exists, isNull, coalesce, if
1. One element per piece, children nested inside; give id="..." to any piece you will change later. <slate title="..." state={{ key: json }}> wraps the root.
2. prop={path or formula} binds live data; prop={`text ${formula}`} fills a sentence; a "quoted string" or {literal} is literal. <text> takes words and {formulas} between its tags.
3. Bare attributes are meaning, never style: tone (muted, good, warning, bad), strong, small, primary, mono. No colour, pixels or font.
4. Bind a list to a table's items and put one <col /> inside per column; item and index read the row.
5. A press reaches you only through an action: onPress={send("...", { with: [paths] })}; text is literal, the changing parts ride with.
6. Write once, then change one piece by its id or set state; do not rewrite the slate every turn.
<slate title="Pull request">
  <column id="root">
    <empty
      id="none"
      title="No pull request yet"
      body="This thread's branch has no pull request."
      when={pr.number == null}
    />
    <facts id="head" when={pr.number != null}>
      <fact label="State" value={pr.word} />
      <fact label="Review" value={pr.review} />
      <fact
        label="Mergeable"
        value={pr.mergeable}
        tone={pr.mergeable == 'mergeable' ? 'good' : (pr.mergeable == 'conflicting' ? 'warning' : 'muted')}
      />
    </facts>
    <table id="checks" items={pr.checks} key={item.name} empty="No checks yet" when={pr.number != null}>
      <col title="Check" value={item.name} />
      <col
        title="State"
        value={item.state}
        tone={item.state == 'fail' ? 'bad' : (item.state == 'pass' ? 'good' : 'muted')}
      />
      <col
        mono
        end
        title="Took"
        value={item.completedAt ? duration(num(item.completedAt) - num(item.startedAt)) : 'running'}
      />
      <action
        label="Send to agent"
        when={item.state == 'fail'}
        onPress={send("A check failed. Read its log and fix it.", { with: [item.name, item.link] })}
      />
    </table>
    <text id="summary" muted when={pr.number != null}>{plural(len(pr.checks), 'check')}, {pr.additions} added, {pr.deletions} removed</text>
    <button
      id="fix"
      primary
      label="Fix the failing checks"
      when={contains(pluck(pr.checks, 'state'), 'fail')}
      onPress={send("Fix the failing checks on the slate.", { with: [pr.checks] })}
    />
  </column>
</slate>

## Pieces

<column> (core): Stacks children top to bottom.
gap: tight|normal|loose, default "normal"
align: start|center|end|stretch, default "stretch"
flags: tight loose start center end stretch
events: none; children: yes
<column id="limits" tight>
  <meter id="week" label="Weekly" value={usage.week.percent} />
</column>

<row> (core): Places children side by side.
gap: tight|normal|loose, default "normal"
align: start|center|end|between
wrap: boolean, default true
flags: tight loose start center end between wrap
events: none; children: yes
<row id="head" between>
  <text id="branch" mono>{git.branch}</text>
  <text id="ahead" muted>{git.ahead} ahead</text>
</row>

<section> (core): A titled group, optionally collapsible.
title: string, required, binds
note: string, binds
collapsible: boolean
open: boolean, binds, default true
flags: collapsible open
events: onChange; children: yes
<section id="changes" collapsible title="Files changed">
  <table id="files" items={thread.changes.files} key={item.path}>
    <col mono title="File" value={item.path} />
  </table>
</section>

<text> (core): A line or a paragraph.
value: string|number, required, binds
tone: tone, binds
emphasis: normal|strong|quiet, binds
mono: boolean
size: small|normal|large, default "normal"
lines: integer, 1 to 20
placeholder: string
flags: muted good warning bad info accent strong quiet mono small large
events: none; children: no
<text id="free" muted mono>{tokens(thread.context.free)} free</text>

<markdown> (core): Rich text, sanitised; links and images are not fetched.

flags: none
events: none; children: no

</markdown>

tone: tone, binds

size: normal|large

events: none; children: no
<number id="spent" usd label="Spent this thread" value={thread.cost.usd} />

events: none; children: no

## Sources

thread (core): This thread: its status, its last turn, its context, cost, tokens, changes and plan.
thread.{id, title, agent, model, effort, access, computer, project, folder, waitingOn}: string
thread.status: starting|working|needs-you|failed|done|resting
thread.turns: number
thread.lastTurn: { status: string, durationMs: number, waitedMs: number, startedAt: time, endedAt: time, model: string }
thread.cost: { usd } number
thread.tokens: { input, output, cached, cacheWrite, reasoning } number
thread.context: { used, window, free, percent } number
thread.changes: { files: [{ path: string, kind: string, additions: number, deletions: number }], from: string, to: string, moved: [string], shared: boolean }
thread.plan: { steps: [{ text: string, state: pending|working|done }], text: string }
thread.subagents: [{ id: string, title: string, state: string, startedAt: time, endedAt: time }]
update: push; scope: the slate's own thread; cost: none beyond what the app already holds
thread.context: the latest turn that reports it; null on an agent that does not
thread.status: the status mark's own kinds
example: thread.context.used / thread.context.window

usage (core): The plan windows of the account this thread runs on, as its agent last reported them.
usage.account: { key: string, label: string, agent: string, plan: string, address: string, computers: [string] }
usage.windows: [{ kind: session|week|week_opus|week_sonnet|month|overage, usedPercent: number, resetsAt: time }]
usage.{session, week}: { percent: number, resetsAt: time }
usage.status: ok|warning|reached
usage.note: string
usage.burn: { tokensPerMinute, threads } number
usage.credits: { count: number, nextExpiresAt: time }
usage.readAt: time
update: push; scope: the account the thread runs on; cost: one event per turn end
usage.session: the five hour window; none on a keyed sign-in, where usage.note says why
usage.note: why there are no windows, else null
example: pct(usage.week.percent)

cost (core): What this thread's workspace costs to run: the rate now and what it has run up.
cost.{rateUsdPerHour, accruedUsd}: number
update: push; scope: the thread's workspace; cost: none beyond what the app already holds
cost.rateUsdPerHour: 0 on this Mac
example: usd(cost.accruedUsd)

time (core): The clock, so a countdown or an age moves on its own.
time.now: number
time.{today, zone}: string
update: tick; scope: none; cost: one re-evaluation a tick
time.now: ms epoch; ticks each second while a visible piece reads it
example: until(usage.week.resetsAt)

git (core): The thread's checkout: branch, head, counts against upstream.
git.{branch, head}: string
git.{ahead, behind, changed, stashes}: number
git.{editsUnread, countsUnknown}: boolean
git.readAt: time
update: push; scope: the thread's folder; cost: none for the checkout fields
git.branch: null on a folder that is not a checkout
example: git.branch

pr (core): The pull request of the thread's branch and its checks.
pr.{number, additions, deletions, changedFiles, commits, behindBase}: number
pr.{url, base, branch, headOid, headSubject, author, word, unread}: string
pr.state: open|merged|closed
pr.draft: boolean
pr.mergeable: mergeable|conflicting|unknown
pr.review: none|approved|changes_asked|required
pr.checks: [{ name: string, workflow: string, state: pass|fail|pending|skipped|cancelled, link: string, description: string, startedAt: time, completedAt: time }]
pr.readAt: time
update: push; scope: the thread's folder; cost: one gh read per interval; every 30 s while a bound check is pending
pr.number: null while the branch has no pull request
pr.headSubject: the head commit's subject; there is no pr.title
pr.word: the one word every tile says
example: pr.checks

## Actions

set: Writes a state path; nothing reaches the agent.
path: string, required, a state path
value: any, required, binds
consent: none; reaches the agent: nothing
refusal: set writes state paths only. Name a path under state.
onPress={set(state.view, "files")}

toggle: Flips a boolean state path; nothing reaches the agent.
path: string, required, a state path
consent: none; reaches the agent: nothing
refusal: toggle flips state paths only. Name a path under state.
onPress={toggle(state.showAll)}

send: Sends the text to the thread: starts a turn, or joins a running one where the agent steers.
text: string, required
with: list, a list of paths
consent: the press; reaches the agent: the text, a blank line, then slate: {...} with the with values
refusal: The thread is gone. Open another thread.
onPress={send("Go on to the next step.", { with: [git.branch, pr.checks] })}

steer: Sends into the running turn; with nothing running it goes as the next message.
text: string, required
with: list, a list of paths
consent: the press; reaches the agent: as send
refusal: Nothing was running, so it was sent as the next message.
onPress={steer("Stop and look at the failing check first.")}

queue: Sends after the current turn ends; starts a turn when none runs.
text: string, required
with: list, a list of paths
consent: the press; reaches the agent: as send, once the turn ends
refusal: The thread is gone. Open another thread.
onPress={queue("When you are done, open the pull request.")}

fill: Puts the text in the thread's composer without sending; with values follow as a quoted block.
text: string, required
with: list, a list of paths
consent: none; reaches the agent: nothing until the person sends
refusal: Open the thread to fill its composer.
onPress={fill("About this branch:", { with: [git.branch] })}
