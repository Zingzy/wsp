1. One piece per line, children two spaces in; write id: type for any piece you will change later.
2. prop={path or formula} binds live data; prop=`text ${formula}` fills a sentence; a word or a quoted string is literal.
3. Bare words are meaning, never style: tone (muted, good, warning, bad), strong, small, primary, mono. No colour, pixels or font.

  none: empty title="No pull request yet" body="This thread's branch has no pull request." when={pr.number == null}

    - fact label="Review" value={pr.review}

    - col title="Check" value={item.name}
    - col title="State" value={item.state} tone={item.state == 'fail' ? 'bad' : (item.state == 'pass' ? 'good' : 'muted')}
    - col title="Took" value={item.completedAt ? duration(num(item.completedAt) - num(item.startedAt)) : 'running'} mono align=end
    - action label="Send to agent" when={item.state == 'fail'}
      @press send text="A check failed. Read its log and fix it." with=[item.name, item.link]
  summary: text value=`${plural(len(pr.checks), 'check')}, ${pr.additions} added, ${pr.deletions} removed` muted when={pr.number != null}
  fix: button label="Fix the failing checks" primary when={contains(pluck(pr.checks, 'state'), 'fail')}
    @press send text="Fix the failing checks on the slate." with=[pr.checks]

## Actions

set: Writes a state path; nothing reaches the agent.
path: string, required, a state path
value: any, required, binds
consent: none; reaches the agent: nothing
refusal: set writes state paths only. Name a path under state.
@press set path=state.view value="files"

toggle: Flips a boolean state path; nothing reaches the agent.
path: string, required, a state path
consent: none; reaches the agent: nothing
refusal: toggle flips state paths only. Name a path under state.
@press toggle path=state.showAll

send: Sends the text to the thread: starts a turn, or joins a running one where the agent steers.
text: string, required
with: list, a list of paths
consent: the press; reaches the agent: the text, a blank line, then slate: {...} with the with values
refusal: The thread is gone. Open another thread.
@press send text="Go on to the next step." with=[git.branch, pr.checks]

steer: Sends into the running turn; with nothing running it goes as the next message.
text: string, required
with: list, a list of paths
consent: the press; reaches the agent: as send
refusal: Nothing was running, so it was sent as the next message.
@press steer text="Stop and look at the failing check first."

queue: Sends after the current turn ends; starts a turn when none runs.
text: string, required
with: list, a list of paths
consent: the press; reaches the agent: as send, once the turn ends
refusal: The thread is gone. Open another thread.
@press queue text="When you are done, open the pull request."

fill: Puts the text in the thread's composer without sending; with values follow as a quoted block.
text: string, required
with: list, a list of paths
consent: none; reaches the agent: nothing until the person sends
refusal: Open the thread to fill its composer.
@press fill text="About this branch:" with=[git.branch]
